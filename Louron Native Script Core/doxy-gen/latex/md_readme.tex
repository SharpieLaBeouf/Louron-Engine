\chapter{Louron Native Script Core API}
\hypertarget{md_readme}{}\label{md_readme}\index{Louron Native Script Core API@{Louron Native Script Core API}}

The {\bfseries{Louron Script Core API}} is the native C++ scripting interface used to extend behavior and logic in the Louron game engine. ~\newline
 This API enables seamless, real-\/time interaction with scene entities, engine systems, and components from within your own C++ scripts.

\DoxyHorRuler{0}
\hypertarget{md_readme_autotoc_md2}{}\doxysection{\texorpdfstring{Overview}{Overview}}\label{md_readme_autotoc_md2}
Scripts in Louron are created and managed via the {\bfseries{Editor}}, inside the {\ttfamily Scripts/} folder of your project. ~\newline
 Each script is a C++ class that {\bfseries{inherits from {\ttfamily \doxylink{class_louron_1_1_i_script}{Louron\+::\+IScript}}}}, and is automatically compiled into a shared library that the engine loads at runtime.

All script classes are tied to an entity in the scene.

As {\bfseries{{\ttfamily \doxylink{class_louron_1_1_i_script}{Louron\+::\+IScript}} inherits from {\ttfamily \doxylink{class_louron_1_1_entity}{Louron\+::\+Entity}}}}, you can use all the methods and properties of an entity in your script.

\hypertarget{md_readme_autotoc_md9}{}\doxysection{\texorpdfstring{Compiling Script Code DLL}{Compiling Script Code DLL}}\label{md_readme_autotoc_md9}
The editor will take care of the compilation of your script code into a shared library.

Every time you modify a script, and refocus the editor, the engine will automatically compile the script code into a shared library.

You can find the compiled shared library in the {\ttfamily Scripts/\+Generated} folder of your project.

It is not recommended to compile the script code manually, as the editor will take care of this for you.

The compiler used is clang++.exe which is distributed as a tool alongside the Game Engine.

Each time the script project is recompiled, the Script Core API in the Scripts directory will be erased and reset with the one from the engine to ensure no funny business!
