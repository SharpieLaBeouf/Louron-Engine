\doxysubsection{Detailed Description}
\doxylink{class_louron_1_1_entity}{Entity} class representing an object in the scene. 

The \doxylink{class_louron_1_1_entity}{Entity} class is what all scripts inherit from. It provides a way to interact with the engine\textquotesingle{}s ECS (\doxylink{class_louron_1_1_entity}{Entity} Component System).

An \doxylink{class_louron_1_1_entity}{Entity} is merely a unique identifier (UUID) that can be used to access and manipulate components associated with it.

You may get Entities from instantiating Prefabs, or by using the static find method to retrieve them by name or UUID.

Where there is a NULL entity, any callbacks to the engine will simply be ignored.
