Get the scaled delta time of the last frame. 

This returns the time in seconds between the current and previous frame, scaled by the current time scale.
\begin{DoxyItemize}
\item If time scale is {\ttfamily 0.\+0f}, this returns {\ttfamily 0.\+0f}.
\item If time scale is {\ttfamily 1.\+0f}, this returns the actual frame delta time.
\item If time scale is {\ttfamily 2.\+0f}, this returns double the delta time (i.\+e., simulating fast-\/forwarding).
\end{DoxyItemize}

Use this for gameplay elements that should respect time scaling (e.\+g., player movement, cooldowns).
